11 差异表达基因韦恩图与 UpSet 图

输入字段和项目迁移规则见输入规范。代码从能看到 0script 的项目根目录运行。

集合图回答“哪些比较共享差异基因、哪些只出现在某些比较”。它不表示表达量大小，也不能仅凭集合交集判断共同调控机制。输入始终采用第 10 章统一的显著性和倍数阈值。

1. 由比较表生成基因集合

保留 generate_de_list_new 函数。直接读取 contrast_id，不再拆分含下划线的组名。默认分别查看对首时期和相邻时期的比较；全部启用比较另外生成 UpSet 图。每类分别统计全部、上调和下调差异基因。

参数 含义与修改方法
comparison_families 一类名称对应一组比较 ID；可增加 custom，从比较表选任意已完成比较
directions 默认 all/up/down；只看上调写 "up"，不会重新执行 DESeq2
nintersects UpSet 默认显示最大的 30 个精确交集；改 10 只影响展示
venn_first_n 传统韦恩图默认取前 3 个比较，允许 2–5；图名按请求数量标记，实际集合可能更少
venn_styles 默认 default/gradient 两种填色；可只选其一
draw_upset / draw_classic_venn / draw_full_venn 分别控制 UpSet、局部传统图和完整集合图；超过七集合时不画完整韦恩图

1.1 准备数据与入口参数

实现：查看编号脚本。

# 目的：按比较族与方向批量绘制差异基因集合图。
# 关键输出：output_root/比较族/方向/intersections交集数_venn集合数[__标签]/。
#   如 6venn/first/all/intersections30_venn3/；
#   保存 gene_sets.rds、各比较.txt、membership.tsv、exclusive_region_counts.tsv。
#   所选图名为 upset、venn_firstN、venn_default/venn_gradient（PNG/PDF）；全空时以说明文件代替假图。
# 运行位置：项目根目录（能看见 0script）；在本章指定环境的 R 中执行。
# 输出/边界：保存到 output_root 下各比较族/方向目录；不改差异表，也不只保留一种可行样式。
# 共用读取：readRenviron 读取 project.env；Sys.getenv 返回文本，as.numeric/as.integer 将阈值/种子转成数值。
#   更改配置后需重新执行读取与赋值，旧变量不会自动刷新。
# 参数设置（下方为本次取值；不需要修改函数内部实现）：
# comparison_families：命名 list 或 NULL；
#   每个元素为一组比较 ID，如 list(custom=c("Treat_vs_Control","Other_vs_Control"))。NULL 使用比较表生成的比较族；
#   每一族单独画集合图。
# directions：只能从 "all"、"up"、"down" 中选一个或多个，多个写 c("all", "up", "down")。
#  "up"：差异表中 direction=up 的上调基因；"down"：direction=down 的下调基因。
#  "all"：上述两类的并集，不包含 ns，不是全部被检验基因；方向均相对比较表的参照组。
#  第 11 章只据此选集合；第 14/19 章会对所选方向分别做富集，不合并为同一次检验。
# nintersects：正整数；UpSet 图最多显示的交集数量。减少只压缩展示，不删除保存的基因集合。
# venn_first_n：整数 2–5；经典韦恩图取前几个集合，顺序来自选定比较族；集合多时还可看完整 UpSet。
# venn_styles：完整韦恩图填色，单选或多选 c("default", "gradient")。
#  "default"：ggVennDiagram 默认填色；"gradient"：黄—绿—蓝渐变填色。
#  两者的区域成员和计数相同；只有 draw_full_venn=TRUE 且集合数适用时才绘制。
# draw_upset：单个 TRUE/FALSE；TRUE 保存 UpSet 精确交集图，FALSE 不画此类图。
#  多集合时优先用它辨认交集；不会删除成员表或改变显著性筛选，空集合另作说明。
# draw_classic_venn：单个 TRUE/FALSE；TRUE 画所选比较族前 venn_first_n 个集合，FALSE 跳过。
#  局部韦恩图不能代替全部集合的精确交集；实际集合少于两组时不强画。
# draw_full_venn：单个 TRUE/FALSE；TRUE 尝试画完整 ggVennDiagram，FALSE 跳过。
#  只在 2–7 个集合时绘制；超过七个集合看 UpSet，不因 TRUE 就强制生成不适用的图。
# output_root：字符路径；本步骤输出根目录，函数再按比较/参数建立子目录。通常沿用；试算可选新目录，但后续读取位置不会自动更新。
# variant_label：一个文本标签，默认 "" 表示不加额外后缀；如 "large_font" 会给末级结果目录加 __large_font。
#  非空时只用字母、数字、点、下划线、短横线，首字符为字母或数字；不填路径、空格或 NA。
#  调整未进入目录名的图幅、字体等时用不同标签另存；标签本身不改变计算参数。
#  它不是强制覆盖开关：同一路径参数冲突仍停止，不修改旧结果清单。
# 调用：先加载脚本，再设置参数，最后运行函数。改值后重新执行赋值和调用。

source("0script/tools/metadata.R")
source("0script/tools/outputs.R")
readRenviron("0script/project.env")
source("0script/scripts/11_sets.R")
comparison_families <- NULL
directions <- c("all", "up", "down")
nintersects <- 30
venn_first_n <- 3
venn_styles <- c("default", "gradient")
draw_upset <- TRUE
draw_classic_venn <- TRUE
draw_full_venn <- TRUE
output_root <- "6venn"
variant_label <- ""
# interface-parameters: sets
run_sets(
  comparison_families = comparison_families,
  directions = directions,
  nintersects = nintersects,
  venn_first_n = venn_first_n,
  venn_styles = venn_styles,
  draw_upset = draw_upset,
  draw_classic_venn = draw_classic_venn,
  draw_full_venn = draw_full_venn,
  output_root = output_root,
  variant_label = variant_label
)

查看本步关键文件

默认例查看 all_enabled 比较族及当前第一个方向；自选 list 则查看第一个非空比较族。membership 的 1/0 表示是否属于集合，signature 的每一位依次对应比较列，count 是精确交集数量；全空时查看 NO_SIGNIFICANT_GENES.txt 提示。

# 目的：只读当前参数路径的关键文本；留在上一框的 R 会话，不重新分析。
# 前提：上一分析已成功或明确提示完整结果复用；若报错/冲突，先处理，不把旧文件当本次成功结果。
# preview_dir/preview_files 只用于查看，不是传给分析函数的新参数。
# file.path 拼接路径；readLines(n = 10) 最多读前 10 行，含表头；不整表读入内存。
# file.exists 检查是否存在；cat 用 sep = "\n" 逐行显示；warn = FALSE 省略末行换行提示。
# nzchar 判断标签是否非空；非空时按原命名规则在末级目录加 __标签。
if (is.null(comparison_families)) {
  preview_family <- "all_enabled"
} else {
  preview_nonempty <- names(comparison_families)[lengths(comparison_families) > 0]
  stopifnot(length(preview_nonempty) > 0)
  preview_family <- preview_nonempty[1]
}
preview_dir <- file.path(output_root, preview_family, directions[1],
  parameter_tag(intersections = nintersects, venn = venn_first_n))
if (nzchar(variant_label)) preview_dir <- paste0(preview_dir, "__", variant_label)
preview_files <- file.path(preview_dir, c("membership.tsv", "exclusive_region_counts.tsv"))
for (preview_file in preview_files) {
  cat("\n文件：", preview_file, "\n")
  if (file.exists(preview_file)) {
    cat(readLines(preview_file, n = 10, warn = FALSE), sep = "\n")
  } else {
    cat("尚无此文件：核对上一步是否完成、是否选择该分析，以及空结果提示。\n")
  }
}

2. 怎样读这些输出

  • gene_sets.rds 和按比较命名的 TXT 保存集合本身，图形不是唯一结果。
  • membership.tsv 每行一个基因、每列一个比较，1 表示属于该集合。
  • region_101000.txt 的位数及顺序对应 membership 列顺序：此例只属于第 1、3 个集合，不属于其余集合。
  • venn_first3 明确只显示该类别前三个比较；完整六集合韦恩图保留，但阅读多集合时优先查看 UpSet。
  • UpSet 默认显示最大的 30 个精确交集，完整交集仍在表中，不能把未画出的交集说成不存在。

3. 本次结果

以下是 6 个“相对 ZT0”比较的全部差异基因集合。UpSet 中首个高柱的 425 表示只出现在 ZT1_vs_ZT0 集合、而不出现在其余五个集合中的基因数，不是 ZT1_vs_ZT0 的全部差异基因数。

同一组集合保留两种六集合韦恩图填色；局部细节另存前三个比较的传统韦恩图。三集合图的区域不等同于六集合的精确交集，因为它没有排除后三个集合。
