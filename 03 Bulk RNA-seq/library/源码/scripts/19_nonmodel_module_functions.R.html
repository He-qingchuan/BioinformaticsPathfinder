# 运行位置：能看见 0script 的项目根目录。R 函数库通过 source 加载定义及共用依赖；调用函数才执行本文件
#   对应的分析/写出。
# 改参方式：在同编号 MD 的参数入口赋值，再执行下面的具名调用；函数默认值只在该形参未传入时使用。编辑文

# 接口说明：每个函数前列出用途、形参和输出；嵌套函数读取的外层变量属于闭包，不能误当成漏传的独立参数。

# 接口｜plot_nonmodel_modules：以已有 Mfuzz 模块成员和自建 OrgDb 重做模块富集。
# 参数（默认值以本函数签名为准；明确传参会覆盖默认值）：
# method（默认 "diamond"）：字符路线名；当前非模式实现仅接受 diamond，不能填一个未实现的方法名称来切换
#   软件。
# top_var_props（默认 c(0.1, 0.2)）：比例向量 (0,1]；用于定位第 16 章已经完成的高变基因组合，如 c(0.1,
#   0.2)。这里不重新挑选基因/聚类，所列组合必须有匹配的保存对象。
# cluster_numbers（默认 6:10）：整数向量，元素至少 2；第 16 章逐一运行这些 Mfuzz 聚类数，第 19 章读取
#   对应已有组合；选中基因数须足够。
# markGenes_num（默认 NULL）：非负整数；优先标记的高变基因数量，总数而非每个模块各 N 个。0 不标基因；
#   第 19 章允许 NULL 沿用保存名单，不改变聚类成员。
# enrichment_top_n（默认 5）：正整数；每个模块图上最多展示的 GO 条目数，不是标记基因数，只显示通过
#   enrichment_fdr 的条目。重绘入口可不重算；完整分析入口改此值仍会执行相应分析步骤。
# enrichment_fdr（默认 0.05）：数值 (0,1]；模块富集图取 p.adjust 不大于此值的 GO 条目，每个模块的检验
#   先完成 BH。没有达标条目时显示明确空结果提示。
# enrich_type（默认 "BP"）：单个 BP、MF、CC 或 ALL；指定模块 GO 富集的本体，改变时需要相应富集结果，不
#   能只重写图标题。
# minGSSize（默认 10）：正整数；与输入/背景匹配后的基因集中允许的最少基因数。提高会排除较小条目，改变
#   参与检验的条目集合。
# maxGSSize（默认 500）：正整数，且不小于 minGSSize；允许的最大基因集规模。降低会排除过大的条目，改变
#   检验范围。
# label_versions（默认 c(FALSE, TRUE)）：逻辑向量；FALSE 不显示已选标记基因标签，TRUE 显示，c(FALSE,
#   TRUE) 保存两版。仅控制标签呈现，不改变点的位置、检验结果或模块成员。
# label_size（默认 10）：正数；时间聚类热图中标记基因的字号，通常从 10 调整，经 genes.gp 传给绘图函数
#   ；不改变标签名单或聚类结果。
# cluster_root（默认 "10Time_Series"）：字符路径；已完成的第 16 章聚类根目录，配合比例、模块数、
#   cluster_variant 定位保存对象。不是本步新聚类的输出。
# output_root（默认 NULL）：字符路径；本步骤输出根目录，函数再按比较/参数建立子目录。通常沿用；试算可
#   选新目录，但后续读取位置不会自动更新。
# cluster_variant（默认 ""）：字符末级目录名；对应第 16 章已有 mark/GOtop/seed 变体，无此层的旧结果留
#   空，按真实路径填写，不自动猜选。
# variant_label（默认 ""）：字符标签；空字符串为默认路径。给次要排版或另一方案另存时用 large_font 等简
#   短标签，仅允许字母数字及 . _ -，首位为字母数字；不能放路径或空格。
# 返回/写出与边界：保存模块 GO BH 结果及带侧栏热图，不重新聚类；缺少选定比例/模块数/变体的保存对象时报
#   错。
plot_nonmodel_modules <- function(method = "diamond", top_var_props = c(0.1, 0.2), cluster_numbers = 6:10,
                                   markGenes_num = NULL, enrichment_top_n = 5, enrichment_fdr = 0.05,
                                   enrich_type = "BP", minGSSize = 10, maxGSSize = 500,
                                   label_versions = c(FALSE, TRUE), label_size = 10,
                                   cluster_root = "10Time_Series", output_root = NULL,
                                   cluster_variant = "", variant_label = "") {
  stopifnot(length(top_var_props) > 0, all(top_var_props > 0 & top_var_props <= 1),
            length(cluster_numbers) > 0, all(cluster_numbers >= 2),
            is.logical(label_versions), length(label_versions) > 0, !anyNA(label_versions))
  if (!is.null(markGenes_num)) stopifnot(length(markGenes_num) == 1, is.finite(markGenes_num),
    markGenes_num >= 0, markGenes_num == floor(markGenes_num))
  annotation <- load_nonmodel_annotation(method, require_kegg = FALSE)
  if (is.null(output_root)) output_root <- file.path(annotation$route_dir, "module_enrichment")
  for (prop in top_var_props) {
    for (k in cluster_numbers) {
      source_dir <- file.path(cluster_root, paste0("top_var_prop_", prop), paste0("Clusters_num_", k))
      if (nzchar(cluster_variant)) source_dir <- file.path(source_dir, cluster_variant)
      cm <- readRDS(file.path(source_dir, "cluster_object.rds"))
      labels <- readLines(file.path(source_dir, "marked_genes.txt"), warn = FALSE)
      if (!is.null(markGenes_num)) {
        selected <- read.delim(file.path(source_dir, "selected_genes.tsv"))
        labels <- head(selected$gene_id, markGenes_num)
      }
      stopifnot(all(labels %in% cm$wide.res$gene))
      output_dir <- file.path(output_root, paste0("top_var_prop_", prop),
                              paste0("Clusters_num_", k))
      output_dir <- file.path(output_dir, parameter_tag(GOtop = enrichment_top_n, fdr = enrichment_fdr))
      claim <- claim_result_dir(output_dir,
        effective_parameters(plot_nonmodel_modules, environment(), c("cluster_root", "output_root", "variant_label")),
        list(cluster = file.path(source_dir, "cluster_object.rds"), labels = labels,
          annotation = annotation_fingerprint(annotation$OrgDb)), variant_label)
      if (claim$reuse) next
      output_dir <- claim$path
      # 完整检验与图中取 Top 分开：修改条目数不会改变这张 BH 表。
      table <- module_enrichment_BH(cm, annotation$OrgDb, "GID", enrich_type,
        minGSSize = minGSSize, maxGSSize = maxGSSize)
      write.table(table, file.path(output_dir, "cluster_enrichment_BH.tsv"),
                    sep = "\t", quote = FALSE, row.names = FALSE)
      writeLines(unique(cm$wide.res$gene), file.path(output_dir, "clustered_background.txt"))
      ids <- sort(unique(cm$wide.res$cluster))
      panels <- make_enrichment_panels(table, ids, topn = enrichment_top_n, fdr_cutoff = enrichment_fdr)
      for (label in label_versions) {
        # 接口｜draw_plot：在当前设备绘制外层准备好的聚类热图。
        # 参数：无显式形参；所需上层对象/输入见功能说明及下方读取语句。
        # 返回/写出与边界：无形参；读取外层 cm、标记名单、面板和排版参数等对象。只绘图，不在闭包中重新跑 Mfuzz。
        draw_plot <- function() {
          args <- list(object = cm, plot.type = "both", line.side = "left", column_names_rot = 45,
            show_row_dend = FALSE, cluster.order = seq_along(ids), gglist = panels,
            ggplot.panel.arg = c(max(5, enrichment_top_n), 0.5, 11, "white", NA))
          if (label && length(labels)) {
            args$markGenes <- labels
            args$genes.gp <- c("italic", label_size, "#23313F")
          }
          do.call(ClusterGVis::visCluster, args)
        }
        stem <- if (label) "pheatmap_go_markGenes" else "pheatmap_go"
        save_time_heatmap(draw_plot, file.path(output_dir, stem), width = 17,
                           height = cluster_heatmap_height(length(ids), topn = enrichment_top_n))
      }
      writeLines(labels, file.path(output_dir, "marked_genes.txt"))
      finish_result_dir(claim)
    }
  }
}
