# 03 参考基因组准备

本章先下载并统一命名，再提取转录本与基因的对应表。所有命令在项目根目录运行。已有完整参考时跳过下载；矩阵入口可跳过本章，富集仍需匹配的基因注释。

## 1. 去哪里找，下载哪些文件

植物从 [Ensembl Plants](https://plants.ensembl.org/) 搜索物种学名，人、小鼠等脊椎动物从 [Ensembl](https://www.ensembl.org/) 搜索。进入物种下载页，确认组装，再到明确的 release 目录：

- 植物：[Plants 发布目录](https://ftp.ensemblgenomes.ebi.ac.uk/pub/plants/)。
- 脊椎动物：[Ensembl 发布目录](https://ftp.ensembl.org/pub/)。

序列位于 `release-编号/fasta/物种/dna/`、`cdna/`、`pep/`，GTF 位于 `release-编号/gtf/物种/`。找到下表中的文件，右键复制完整链接。其他类群按物种选择合适来源，不一定在这两个站点。

| 文件 | 一般选择 | 本项目统一名称 | 用途 |
| --- | --- | --- | --- |
| 基因组 DNA | `dna.toplevel.fa.gz` 或合适的 `dna.primary_assembly.fa.gz` | `genome.fa.gz` | Salmon 基因组诱饵 |
| 转录本 | `cdna.all.fa.gz` | `transcripts.fa.gz` | 定量对象 |
| 结构注释 | 同组装、同 release 的 GTF | `annotation.gtf.gz` | 提取转录本—基因关系 |
| 蛋白，可选 | `pep.all.fa.gz` | `proteins.fa.gz` | 第 18 章非模式支线 |

四类参考的物种、组装和发布版本应匹配。CDS、cDNA、蛋白不能互相替代；GFF3 不能改后缀冒充 GTF。`cdna.all` 不表示已经包括所有 RNA 类型，ncRNA 需另行核实范围；改变参考范围后要重新建索引和定量。

### DNA 文件名怎样理解

`dna` 是未屏蔽序列，本流程优先使用；`dna_sm` 用小写标记重复区域，仍保留碱基；`dna_rm` 用 N 屏蔽重复区域，不用于替换本案例参考。

`toplevel` 和 `primary_assembly` 表示序列集合，而非屏蔽方式。前者可含替代单倍型/补丁，后者排除这些区域；人类示例选择 primary assembly，拟南芥示例使用 toplevel。不要将每条染色体和完整集合重复合并。定义见目录中的 [DNA README](https://ftp.ensembl.org/pub/release-111/fasta/homo_sapiens/dna/README)。

### 自备参考与查看文件开头

自备参考仍采用上述四个通用名称，放在 `1database/genome`。记录提供方、组装、release 和真实来源；不能只修改配置中的物种名却继续使用旧物种文件。这三套 release 是明确的复现示例，不表示新项目必须采用同一 release。

准备完自己选择的一套后，可以在 `rnaseq` 环境的 R 中查看文件开头。FASTA 的 `>` 行是序列 ID，其后是碱基或氨基酸；GTF 开头常有 `#` 注释，数据行为制表符分隔的九列，最后一列包含 gene_id/transcript_id 等属性。仅看开头不等于完整性校验。

```r
# 目的：只读参考文件的前 10 行，不全量解压、不覆盖任何文件。
# reference_files：本项目约定的文件名；蛋白可选，不存在时明确提示并跳过。
# gzfile(..., open = "rt")：以压缩文本连接读取；n = 10：最多 10 行。
# warn = FALSE：不提示末行换行问题；close：用完连接即关闭，避免一直占用文件。
# cat 的 sep = "\n"：按原来的行逐行显示。
reference_files <- c("genome.fa.gz", "transcripts.fa.gz", "annotation.gtf.gz", "proteins.fa.gz")
for (reference_file in file.path("1database/genome", reference_files)) {
  cat("\n文件：", reference_file, "\n")
  if (file.exists(reference_file)) {
    reference_connection <- gzfile(reference_file, open = "rt")
    reference_lines <- tryCatch(
      readLines(reference_connection, n = 10, warn = FALSE),
      finally = close(reference_connection)
    )
    cat(reference_lines, sep = "\n")
  } else {
    cat("尚未准备此文件；蛋白仅在相应支线需要。\n")
  }
}
```

### 下载失败与来源校验

中断后保留同一来源的 `.part` 续传。摘要不符或解压失败时先核实来源，再单独隔离损坏文件，不删除整套参考。不要向不同 URL 的旧片段续传，也不要将不明软链接作为下载目标。

`gzip -t` 只验证压缩完整性，不证明来源。官方目录如有 `CHECKSUMS`，应保存并按同目录说明核对：Ensembl 这里常用 `sum -r` 的 BSD 校验数和块数，**不是 MD5**，核对条目仍用官方原名。提供方有 MD5/SHA256 时，可将“本地路径—原始摘要—来源”整理为第 04.5 章的 `checksums.tsv`；没有时报告明确提示未完成官方摘要验证。已有来源记录继续保留。

本案例样本来自 Ws-2，而参考为 Columbia 背景；使用时保留这一差异说明，不仅凭品系差别解释所有未匹配 reads。
