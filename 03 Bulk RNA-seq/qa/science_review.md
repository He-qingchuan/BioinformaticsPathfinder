# 读图说明的核对口径

核对以本包原图、对应小表、完整 ZT4_vs_ZT0 差异结果和已复制的实现为基础，补充阅读 FastQC、Salmon、EnhancedVolcano 官方说明。没有从示意图生成研究结果，没有重新拟合统计模型。

- **数据单位**：21 个双端文库与 42 个 FASTQ 文件分开；fastp 的 reads 数与 Salmon 的片段对数对应；21 文库保留率图是横向条形图，横轴为百分比，纵轴为文库。
- **FastQC**：逐位置质量图的平均线、中位数、四分位箱、10–90 百分位须与背景区间分别解释。前后 Adapter Content 图都采用 0–100% 纵轴，累计接头信号不能解释为该位置的接头碱基比例。
- **样本关系**：PCA 一点一文库，PC1 / PC2 分别解释约 46.42% / 20.87% 变异；相关性每格对应一对样本，不因颜色偏浅就等于负相关。
- **差异与集合**：原表 15,312 行，经典与增强火山图均用 15,310 条有效绘图记录；两条 pvalue 缺失记录未画出。经典候选统计为上调 1,087、下调 826；增强火山图四色区分两个阈值的通过情况。安装的 EnhancedVolcano 1.28.2 代码采用严格阈值比较，详解与原表的包含等号规则分开表述。Venn / UpSet 区分两两交集、精确交集和参与集合范围。
- **热图**：Top30 按绝对 log₂FC 选择，使用 log 转换后的 TMM 表达做行标准化。AT4G31073 的 padj 约 0.106，说明进入 Top 图不等于显著；一个色格是一个基因在一个样本中的相对值。
- **ORA**：官方 GO 的示例比例为 26/809 与 41/11616；KEGG 为 32/302 与 111/4202。自建 GO 路线的水分响应示例为 30/332 与 137/4596。有效分母、背景与富集倍数逐一从原表核对。
- **GSEA**：单条目图按秩位置画运行分数，不是时间曲线。官方酸性物质响应条目 setSize 为 359、核心成员 93、NES 约 1.932；点图的 Count 按核心成员数解释。已读取安装的 enrichplot 1.30.4 的 fortify_internal：gseaResult 的 Count 由 core_enrichment 构造，GeneRatio 为 Count/setSize。自建路线另选碳水化合物代谢条目，不能把两个不同条目当作同一检验直接比较曲线高低。
- **时间分析**：Mfuzz 细线是一条基因轨迹，粗线为模块各时期的中位趋势；等距摆放的时期不是等间隔小时刻度。JTK 使用 6 个等间隔时期、18 个重复观测列；真实面板的红线是均值连线，纵轴逐面板取范围，不是正弦拟合。
- **注释与示意**：覆盖图以 27,628 个代表蛋白对应的基因为共同分母，类别重叠。14 张新 SVG 均标为教学示意；小例子中的数字、集合、波形与隶属度不冒充本例实测数据。
