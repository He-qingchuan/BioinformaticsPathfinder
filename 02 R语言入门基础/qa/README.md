# 验证范围

`check_r.py` 在每节各自的临时项目、新 R 进程中执行 35 份完整脚本，比较已提交参考输出，检查图像产出。`--record` 是显式维护操作，普通检查不会修改期望结果。全局环境、时间区和字体缓存不依赖其他项目；使用 UTF-8 读取输出。

`check_semantics.py` 执行记录守恒、缺失计数、Welch 手算公式、OLS 斜率恒等式、报告数字追溯、新批次迁移、无效输入拒绝、全缺失分组与重复连接键检查。检查不只确认“代码没报错”。

`validate.py` 核对章节、术语、插图、链接与锚点，将教材搬到含中文及空格的新位置，禁止访问原仓库、网络及子进程后重建，检查产物一致。

`browser.cjs` 验证地图/目录、不同屏宽、每个章节入口、术语查询与返回、进度、键盘、动画暂停、减少动态偏好、无脚本、禁用存储、打印及离线加载。

实际运行报告与截图位于被 Git 忽略的 artifacts 中，GitHub Actions 上传验证产物。统计图的字形/抗锯齿可能因操作系统不同而变化，跨平台检查图形产出和数值语义，不假定像素完全相同。

本地最初使用已有 R 4.5.3 环境验证兼容性；R 4.6.1 的 Windows、macOS 和 Linux 自动检查由工作流记录。通过的自动代码检查不等于在每个系统实际点击完成过 RStudio 安装，环境准备说明以官方文档为依据。
