## 先选一条适合自己的入口

本课的命令使用 **Ubuntu 24.04 LTS、Bash 和 GNU 常用工具**作为基准。已经有 Ubuntu 的，可以直接练习；Windows 可以用 [[wsl|WSL]]；已有 Linux 服务器的，可以通过 [[ssh|SSH]] 登录。网页和术语阅读本身不要求安装这些软件。

| 现在的情况 | 从哪里开始 |
| --- | --- |
| 已经在 Ubuntu 中 | 打开“终端”应用 |
| Windows，尚无 Linux 环境 | 按下面的 WSL 路线准备 |
| 已有服务器账号 | 看资料页的“SSH 与文件传输”，登录后使用自己的家目录 |
| macOS，或暂时不能安装 | 先阅读和操作网页图解；实操使用 Ubuntu 虚拟机或已有服务器 |

macOS 的终端并不等于 Ubuntu，其默认 Shell 和部分命令选项也不同。本课暂不把 macOS 原生命令环境当作验证基准。

## Windows：把安装命令和课程命令分开

以下这一条是 **Windows 终端／PowerShell 的安装命令**，需要按系统提示使用管理员权限，并可能需要重新启动。先保存手头的工作。

```powershell
wsl --install -d Ubuntu-24.04
```

如果这台电脑已经安装过 WSL，先用 `wsl --list --verbose` 查看已有发行版；有可用 Ubuntu 就不必重复安装。安装遇到系统版本或虚拟化提示时，按[微软 WSL 官方说明](https://learn.microsoft.com/en-us/windows/wsl/install)处理。

打开 Ubuntu 后，按提示创建你自己的 Linux 用户名和密码。输入密码时屏幕可能不显示字符，这不代表键盘失灵。后续课程中的 Bash 命令都在 **Ubuntu 终端**运行。

## 把材料放到自己的工作台

下载资料页中的 **练习材料 ZIP**，解压后得到 `linux-lab` 文件夹。请保留原始下载作为备用，并将一个练习副本放进 Linux 的[[home|家目录]]。

- Ubuntu 桌面：用文件管理器把文件夹复制到“个人文件夹”。
- WSL：在 Windows 文件资源管理器地址栏进入 `\\wsl.localhost\Ubuntu-24.04\home`，打开自己的 Linux 用户目录，再复制文件夹。发行版名应与实际安装名称相同。
- 远程服务器：使用服务器提供的文件传输方式，把整个目录放进自己的家目录；没有服务器也完全可以完成主线。

{{figure:tree}}

`notes` 放文字笔记，`logs` 放日志，`tables` 放表格，`tools` 放一个小示例程序，`results` 用来接住后面产生的结果。这些只是便于理解的目录名称，Linux 并不强制你这样命名。

## 怎样重新开始

如果想重做练习，先通过文件管理器把当前工作目录改名保留，再从 ZIP 解出一个新副本。这样既能回看自己做过什么，也不用用一条大范围删除命令清空文件。

每节的示例都说明起始位置；随包材料足够支撑任意一节独立重做。网页里的“参考输出”只用于对照，自己的家目录名称、时间和部分排列顺序可能不同。
