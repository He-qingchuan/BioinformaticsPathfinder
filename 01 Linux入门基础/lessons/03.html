提示符是在说：现在轮到你了

打开终端后，常见的一行文字像这样：

示意内容，不作为命令执行
river@station:~$

这是提示符的一种样式。river 可能是用户名，station 可能是机器名，~ 通常表示家目录，$ 常见于普通用户的提示符。样式可以自定义，因此不要仅凭颜色或一个符号判断权限。

输入命令时，不要把教程里的提示符一起输入。 本教材可复制的命令块都不包含提示符。

先让终端回应一次

这组命令可以在任意目录运行。第一条 echo 把文字显示出来；第二条 printf 按给出的格式输出，其中 \n 表示换行。单引号把整段文字交给命令，我们会在第 8 节细讲引号。

Bash · 输入命令
echo '你好，Linux！'
printf '一条命令，一次观察。\n'
参考输出
你好，Linux！
一条命令，一次观察。

下载这段命令 ↓

按一次回车执行一行。命令结束后，Shell 再显示提示符。输出不是接下来需要再输入的命令；复制按钮只复制输入部分。

看看身边有什么

输入 pwd，它会显示当前工作目录。再输入 ls，它列出当前位置下的名字。现在先把它们理解为“我在哪儿”和“这里有什么”，下一节再走进目录。

Bash · 输入命令
pwd
ls

命令一般由名称、选项和参数组成。例如 ls -l notes 中，ls 是命令名，-l 选择详细列表，notes 指定要查看的目录。选项也是一种参数，只是有特定用途；不是每个命令的参数规则都一样。

不记得时，先问工具自己

对 ls 可以试 ls --help。这不是所有程序统一支持的规则，但很多 GNU 工具支持它。也可以用 man ls 看手册；进入后按 q 退出。最小化系统可能没有安装手册，遇到 man: command not found 时先用 --help。

cd 是 Shell 的内建命令，它的帮助可以用 help cd 查看。不要以为所有命令都一定对应磁盘上的独立程序。

三个能立刻用上的小动作

  • 输入一部分文件名后按 Tab：尝试补全；候选不止一个时继续输入或再次按 Tab。
  • 按 上方向键：找回最近输入过的命令，检查后再执行。
  • 按 Ctrl+C：通常请求中断当前前台任务。它不是“撤销”，不会自动恢复已经写入的文件。

文字终端来自很早的计算机交互方式。今天的终端窗口保留了这种逐行输入和响应的形式，但背后已经可以运行非常丰富的程序。
