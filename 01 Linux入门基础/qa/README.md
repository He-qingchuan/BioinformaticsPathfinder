# Linux v1.0.0 验证说明

- `check_practice.py`：在独立临时副本运行 16 组命令，先断言实际文件和结果语义，再比对参考输出；另测完整脚本重复运行、含空格和中文路径、输入缺失、没有 WARN、参数缺失、输出失败。
- `validate.py`：检查 18 节先修顺序、练习与答案、术语字段、页面锚点、本地资源、无远程运行资源，以及独立复制后禁止读取原项目和联网的确定性重建。
- `browser.cjs`：检查全部课程、四个小演示、术语查询与返回、无脚本阅读、进度、窄屏、离线资源、HTTP 路由与打印展开。

自动结果保存在 `artifacts`，不把临时截图和运行记录当作教材源文件。GitHub Actions 使用 Ubuntu 24.04；本机检查环境另记录在 practice.json 中。仅完成了某一种检查时，不据此声称其他环境已验证。

网络安装示例、WSL 系统安装、SSH 连接属于环境相关说明，不由命令测试自动执行。没有真实远程账号时，不宣称验证过服务器连接。手工编辑器操作需要读者在自己的终端完成。
