# V3 术语新读者审读

2026-09-16。按 doc-coauthoring 的 Reader Testing 工作流，由未读取会话上下文的独立审读者阅读词条及必要的既有图解，完成两轮检查。未改动课程正文、图解或分析材料。

第一轮的八个问题都能从条目及其关联入口正确回答：

| 问题 | 从词条获得的结论 |
| --- | --- |
| 隶属度 0.8 是概率或细胞比例吗？ | 不是；它是当前模糊聚类中的渐变归属程度。保留专业译名并补充直白说明。 |
| counts、Count、NumReads 是否相同？ | 区分基因估计表达计数、转录本估计片段计数、富集图成员计数。 |
| 本案例 TMM 是否 TMM-CPM？ | 不是，按本课 Trinity 实现解释为 TPM / norm.factor。 |
| P 值、padj、FDR 是什么概率？ | 区分零假设下的统计证据、多重校正和长期平均错误发现比例，均不当成单个候选为假的概率。 |
| GSEA Count 与 setSize 为什么不同？ | 一个数本课核心富集成员，一个数完整有效集合成员。 |
| 趋势粗线是否为 Mfuzz 算法中心？ | 不是，是模块内展示基因逐时期标准化值的中位数。 |
| 24 小时周期能否证明内源节律？ | 不能，须考虑环境驱动、观察时长与额外实验。 |
| ORA 富集 9 倍是否代表表达 9 倍？ | 不是，它比较候选比例与背景比例。 |

第一轮的五处修改已落实：把隶属度的概率否定句写得更直接；就地解释 norm.factor；明确趋势中位数线的对象和尺度；解释自由运行；将接头图的累积口径改写为逐位置计入的具体过程。

第二轮复查上述修改，并审读补充的实验、质控与注释概念。提出的三处修改已落实：文件摘要只用于核对字节内容，不能单独证明副本独立；百分位数明确为分界数值；区分生态型与遗传背景。

维护者另据原文修正了 Top30 入选口径和趋势图等距显示的解释，并检查普通“背景”不误链到富集背景、FastQC“模块”不误链到表达模块。科学口径参照包内图解和实际分析说明，未重新计算真实结果。
