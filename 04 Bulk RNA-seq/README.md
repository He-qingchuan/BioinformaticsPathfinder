# 转录组海岛探险 · V3 术语增强版

**开始学习：打开 [01_海岛探险教案.html](01_海岛探险教案.html)。** 这是地图与交互课程入口。

**连续阅读或打印：打开 [02_完整教案_阅读与打印.html](02_完整教案_阅读与打印.html)。** 两个入口共用同一套课程内容。分享时发送完整 ZIP；请先解压，再打开 HTML，并保留整个文件夹。

## 本次只增强术语

术语由 26 项扩充到 **178 项**，提供中英文名、适用缩写、通俗解释、具体例子、本课用途及易混点。每个正文小节和独立图解按首次出现添加虚线入口；地图课程、完整阅读页与放大图解共用同一份解释。可搜索中英文或别名，也可按八类主题浏览。关闭解释后回到原位置。详见 [术语增强说明.md](术语增强说明.md)。

课程正文与逐图讲解没有改写，数据、原图、资料馆和分析源码保持 V2 原字节。V2 与修改前完整备份均单独保留。

## 这份教案是独立的

图片、报告、数据、脚本、样式、交互代码与必要的第三方绘图库均保存在本文件夹。网页只使用包内相对路径；不通过软链接、绝对路径或接口读取 V9 分析项目。**整包移动、改名或复制到另一台电脑后仍可离线阅读。默认重新构建页面也只读取包内素材。**

资料馆中的官方网站链接供自愿延伸阅读，点击它们才需要联网。来源记录中保留的源项目路径用于追溯，不参与网页加载。完整计算需要原始数据、参考库和分析环境；随包源码供阅读与学习，不代表本包收录了全部计算输入。

## 怎样使用

- 点击地图建筑，自由进入各站；也可切换“目录”，或在课程窗口使用“上一站／下一站”。
- 每张真实图先给出浅绿色背景的**摘要**，下面直接展开**读图详解**。从“这是什么图、它回答什么问题”读到数据范围、点线或格子的含义、横纵坐标、图例、真实例子和解释边界。
- “放大读图”同时保留图像与讲解；桌面左右对照，小屏幕上下阅读。“隐藏图中标记”只隐藏数字定位标记，摘要和详解始终保留。
- 新增的原理插图可放大和保存为 SVG。示意数字均标明教学用途，真实结果图仍保留原始数据和原始像素。
- “全屏讲课”扩大课程窗口和字号。小屏幕中的地图、宽表或示意图可在各自区域横向查看，正文正常换行。
- 点击术语查看解释；每站自测可随时查看解析。已读进度尽可能保存在当前浏览器本地，不上传数据；移动文件夹或更换浏览器后可能重新开始记录。
- 完整阅读页展开自测解析，术语链接可直接弹出完整解释，也支持图像放大；禁用脚本时术语链接跳转到页末完整手册。交互实验请在地图课程中使用；阅读页保留实验的静态说明。
- [脚本与资料目录](library/脚本与资料目录.html)提供 27 份 Markdown 阅读页与原文下载，以及 53 个实现脚本、10 个共用工具的完整源码阅读页与下载入口。

## 案例与数据口径

案例结果取自原来已经完成的 `v9_project/projects/arabidopsis_demo` 分析。V2 更新了资料副本和教学内容，没有重新下载、过滤、定量、拟合、聚类或注释真实数据。资料副本为 **2026-09-15** 快照；结果图与代表数据沿用原版精选材料。新脚本中的参数目录、检查与重绘入口按随包原文说明理解，不能据此推断本次重新计算过案例。

原研究数据为 PRJNA1015621 / GSE242964。本案例选择光周期转换后第 2 天的 7 个 ZT 时期、每时期 3 个生物学重复，共 21 个双端文库。差异表达、火山图、热图和功能分析主要围绕 **ZT4_vs_ZT0**；过滤前后用 **ZT4_rep_1 的 R1** 对照。集合与时间图依其分析需要使用多个比较或时期。

原表默认候选阈值为 `padj <= 0.05` 且 `|log2FC| >= 1`，得到 1,087 个上调、826 个下调候选。阈值实验只重新筛选已有的 15,312 条结果，不重新拟合模型。火山图绘制有效点数与图例分类规则的细节见逐图讲解。

非模式支线使用同一批拟南芥材料，演示缺少现成注释时的做法；它不是另一个物种实验或独立重复验证。

## 维护与重新构建

正常学习无需安装 Python、Node 或分析软件。以下命令仅供维护者，在本教案目录运行：

```bash
# 安装有 markdown-it-py 的 Python；只读取本包，重新生成两入口、资料馆和插图。
python tools/build.py

# 核验随包素材摘要、教学关键数值、课程覆盖与本地链接。
python qa/validate.py
python qa/glossary_validate.py

# 需要已安装 Playwright 与 Chromium；执行离线交互、图解和迁移验收。
node qa/browser.cjs
node qa/glossary_browser.cjs
node qa/responsive.cjs
node qa/figures_review.cjs

# 如需以后更新资料，明确指定来源；只复制文档/源码/小型入口表，不导入分析结果。
# 建议先保留整个教案副本。导入会更新本包的 case/0script 和来源记录。
python tools/import_docs.py /path/to/v9_case_project
python tools/build.py
```

不要给默认构建命令传入分析项目路径。源码资料更新与结果素材更新分开进行；本次更新无需完整 V9 项目来重建网页。验收环境与结果见 `qa/README.md`。
