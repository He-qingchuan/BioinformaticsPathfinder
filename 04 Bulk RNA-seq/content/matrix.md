## 把许多样本排进一张表

上一站每个样本有一份转录本定量结果。为了比较样本，我们把结果排成矩阵：**一行一个基因，一列一个样本，每格一个表达数值。**

先根据明确的转录本—基因映射，把同一基因的转录本归到一起；再核对所有样本列的名字与顺序。就像整理成绩单，分数计算正确但列名对错学生，仍然会得出错误结论。

本章调用的是 Trinity 附带的矩阵整理工具。它在这里汇总已有 Salmon 结果，并不在这一步从头组装转录本。

## 为什么有 counts、TPM、TMM 三种数

**counts：保留计数信息。** 本例是 Salmon 估计后汇总到基因的计数，会受到测序深度和组成等因素影响。正式差异分析读入这类矩阵，按既有流程取整，再由 DESeq2 估计所需归一化与模型参数。

**TPM：强调样本内的相对组成。** 先考虑转录本长度，再把丰度缩放到总和一百万。测到更多片段可能是表达更高，也可能是转录本更长；长度因素需要被考虑。

**TMM：缓解样本间的组成差异。** 本项目 Trinity 对 TPM 进行 TMM 因子缩放，得到 `TPM / norm.factor`。它不是另一种原始 read 数，也不是 counts 的 TMM-CPM。

| 任务 | 本案例使用什么 |
| --- | --- |
| DESeq2 正式差异检验 | 基因 estimated counts，进入指定流程时取整 |
| 样本相关性与 PCA | log₂(TMM + 1) |
| 时间趋势与周期输入 | TPM，再按各章节要求过滤和变换 |
| Top 基因热图 | 对选定表达值做行标准化后展示 |

## 归一化是在处理什么问题

文库测得片段多，总计数通常更高；少数极高表达基因占据很大份额，也会改变其他基因的相对占比。归一化帮助我们把部分技术或组成影响与目标变化分开，但它依赖方法假设，不会自动消除所有批次因素。

{{lab:composition}}

这个实验也说明：TPM 是相对组成量。可以谨慎观察其跨样本趋势，但不能把 TPM 的升降直接等同于绝对 RNA 数量改变，更不能把它替代计数送入 DESeq2。

## 一张总量图能告诉我们多少

{{figure:matrix_total}}

各列的估计片段总量不同，提示文库深度并不一致。这张图不是哪个基因表达最高的排名，也不是软件的质量打分。正式模型会进一步处理大小因子与其他统计问题。

本案例基因矩阵有 27,588 行、21 个样本列。未被放入参考或定量范围的基因，不应简单等同于“表达为零”；参考范围、定量范围和有表达信号的范围需要分别讨论。

> 带走一句话：矩阵只是容器，数值的定义才决定它可以送给哪一种分析。
