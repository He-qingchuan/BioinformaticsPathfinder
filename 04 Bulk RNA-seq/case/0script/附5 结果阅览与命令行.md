# 结果阅览与命令行

分析由编号 MD 中的代码完成。网页只读取已经保存的结果，不能上传文件、改分析参数或启动任务。

## 运行章节

在能看到 `0script` 的当前项目根目录，按 MD 中的加载脚本、设置参数、具名调用顺序运行。常改参数写在入口段和具名调用中，注释说明参数含义。单次示例与批量调用任选其一；只改图时优先读取已有统计对象，按相应章节的重绘示例执行。

也可以调用同一份 MD 中明确标记的执行单元：

```bash
# 目的：从命令行解析或运行第 12 章的明确执行入口；不是在网页中上传/分析。先进入项目根目录。
# conda run -n rnaseq python：使用已安装主环境；位置参数 . 指当前项目，12 指章节。
# 第一行 --check：只解析代码与维护依赖，但会更新 runlogs/generated 的入口副本，不生成火山图。
# 第二行 --only volcano：真正执行名为 volcano 的标记单元，读取当前配置、已有差异表和 MD 默认参数；不是直接重新跑上游。
# 关键输出：0script/runlogs/generated/ 是提取副本；实际运行另写带时间戳 .log/.json，
#   并追加 0script/runlogs/execution_history.jsonl（一行一次执行记录，不是完整 JSON 数组）。
# 两行含义不同：解析通过不等于数据都准备好，材料预检见第 04.5 章；正常执行还会保存运行日志和参数/依赖摘要。

conda run -n rnaseq python 0script/tools/run_chapter.py . 12 --check
conda run -n rnaseq python 0script/tools/run_chapter.py . 12 --only volcano
```

| 位置/选项 | 可取值及影响 |
| --- | --- |
| 项目位置 `.` | 当前项目根目录，也可填另一项目的明确路径；该目录内要有 0script |
| 章节 `12` | 1–20 或 4.5，前导零可省略；不接受逗号列表。只有含执行标记的章节才有可运行单元 |
| `--only volcano` | 取当前章 `execute:` 后的真实名称；省略时按正文标记顺序运行所有单元。不填写任意函数名或图名 |
| `--check` | 默认不启用；写出才只解析，不分析。仍生成入口副本，不等同第 04.5 章材料检查 |
| `--params 文件.json` | 省略时用 MD 参数；填写时只覆盖 JSON 中列出的白名单项，不回写 MD 或 project.env |
| `--help` | 显示帮助后退出，不提取、不分析 |

```bash
# 目的：查看既有执行记录，了解执行名、退出码与时间；不会启动任务。
# 每行是一条 JSON；head -n 10 只看开头最多 10 次记录，不把开头记录误当作最近一次。
# 实际某次日志由终端给出的路径确认；未运行过时明确提示，不生成空记录。
if test -f 0script/runlogs/execution_history.jsonl; then
  head -n 10 0script/runlogs/execution_history.jsonl
else
  printf '尚无执行历史；语法检查本身不等于完成分析。\n'
fi
```

执行入口提取 MD 中的参数与调用块，再加载 `0script/scripts/` 下的维护脚本。参数在 MD 调整，实现只在编号脚本维护；`0script/runlogs/generated/` 是执行副本，不直接修改。每次实际调用保存带时间戳的日志、代码 SHA256、依赖脚本摘要和退出码。`--check` 只解析语法，不证明依赖、输入或统计结果正确。

连续且执行名相同的代码框进入同一个进程；不同执行单元不共享 R 内存，需要按 MD 显式加载输入及函数。共享函数直接维护在 `scripts/`。更新后重新运行对应的 `source()`，再调用函数；无需先执行另一章分析或从日志目录导出函数。

参数也可以保存为 CLI JSON，例如 `{"volcano":{"top_n":10,"variant_label":"larger_labels"}}`，再通过 `--params 文件.json` 传入。只接受白名单参数和正确类型，不执行 JSON 中的代码。JSON 参数在 MD 标出的入口点生效，不搜索替换正文中的数字。JSON 中字符串用双引号，逻辑值用小写 `true/false`，多值用数组，如 `"methods":["classic","gradient"]`；数值不要包成字符串。各值含义仍按对应 MD，不能把 R 的 `c(...)` 贴入 JSON。CLI 白名单是更窄的安全接口，不保证暴露全部 MD 参数；完整列表/范围可查 [catalog.py](tools/catalog.py)，未列入时回到 MD 参数段调用，不修改白名单凑通过。完整输出保护规则见附 4。

## 打开网页

当前项目位于 `projects/<项目名>` 时，从项目根目录启动：

```bash
# 目的：启动共享的本地只读结果网页，不开始统计分析。
# bash：运行共享启动脚本；../../web/start.sh：相对于项目根目录的脚本位置；8766：监听端口；用未占用的 1024–65535 整数，换端口时访问地址也须一致。
# 已有服务正常时不重复启动；网页只读取各项目结果和 MD，不提供上传/在线重跑入口。此命令是服务启动操作，不是图片计算命令。

bash ../../web/start.sh 8766
```

本机打开 `http://127.0.0.1:8766`；远程服务器通过 SSH 转发该端口。本服务没有账户系统，不直接开放公网。

“分析步骤”按章节汇集图表和日志；“结果图册”可按比较、类型和文件名筛选；“步骤说明”显示当前项目的 MD。点击图查看该类图的原理与解读、真实比较方向、可用参数及原文件。文件存在不等于分析成功，历史记录也不能证明后来改过的参数已经运行。

新图生成后按“刷新结果目录”。新建项目后重新启动服务以更新项目选择列表。原图和表格归属于各自项目，不被网页改写。

## 可删除的缩略图

`VIEWER_THUMBNAILS=TRUE` 启用缓存，`FALSE` 不用缓存而直接展示原图；只影响显示速度和缓存占用，不修改统计结果。默认值以 project.env 为准。若启用缩略图，只在本项目 `.viewer/thumbs/` 按需生成。新项目没有缓存；缓存不可写或 `VIEWER_THUMBNAILS=FALSE` 时直接展示原图。缓存能重建，不属于结果或统计输入，迁移时不必复制。不要把 `.viewer` 与真实结果中的 PNG/PDF 混为一谈。

准备检查也支持章节入口：`python 0script/tools/run_chapter.py . 4.5`。`04` 与 `04.5` 是不同章节；`--check` 仅做语法解析，要实际检查材料请不要加 `--check`。不提供跨章节一键调度。
