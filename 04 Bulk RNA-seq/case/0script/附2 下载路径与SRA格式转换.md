# 下载来源与历史格式记录

当前获取步骤统一见[第 04 章](<04 转录组测序数据下载或自备.md>)：到网站核对样本，导出下载脚本与元数据，再整理输入。这里不再维护另一套 API 查询、案例筛选、Aspera 或 SRA 批量下载代码。

已有 `ena_runinfo.tsv`、`selected_metadata.tsv`、`download_manifest.tsv` 和下载/迁移日志保留作为本案例来源记录，不要求新项目重新生成这些历史文件。新项目保留自己的导出元数据和提供方摘要即可。

如果某个研究没有可用的双端 FASTQ，需要另行按来源网站解决格式获取问题，再回到本项目统一输入规范；不能把单端或 orphan 文件改名当成配对文件。SRA 导出的 read 头、质量表示和压缩方式可能与 ENA 不同，不能强求不同来源的压缩文件 MD5 一致。

所有路线均需记录实际来源，并在第 04.5 章核对准备状态。当前案例已经有完整 FASTQ，不为重新演示下载而覆盖它们。
