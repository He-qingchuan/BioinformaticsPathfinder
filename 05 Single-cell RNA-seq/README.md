# 单细胞海岛探险

打开 [01_海岛探险教案.html](01_海岛探险教案.html) 开始；连续阅读或打印打开 [02_完整教案_阅读与打印.html](02_完整教案_阅读与打印.html)。请发送完整文件夹或 ZIP，解压后打开，不单独发送 HTML。

16 站课程、34 张精选真实图及逐图详解、16 幅原理插画、16 幅本站数据流、92 项术语、4 个教学互动和每站自测。内容来自人类骨髓历史案例；不随结果网页选择的项目变化。

## 怎样学习

点击建筑进入课程，也可使用目录、上一站/下一站；所有地点开放。每张图先读摘要，再按对象、坐标、颜色、阅读顺序、实际例子和边界逐层理解。放大后保留图文对照；数字定位标记可以隐藏，原图不被改写。

术语入口用虚线标出，支持中英文查询及分类；打印页包含全部词条。全屏讲课调整阅读空间，已读记录尽量保存在当前浏览器；换浏览器或移动位置后可能重新记录。自测随时可看解析。

所有必要资源都在本包内，无需安装分析软件或联网。外部文献链接只有主动点击才联网。教学控件只重新统计随包小表或切换已有图，不运行分析，不改变研究项目。

## 案例口径

H5 主线导入 17,125 枚细胞、36,601 个基因；基础过滤后 17,041 枚细胞、23,427 个基因。历史主线保留双细胞预测标记，选择未整合邻居图。当前新版候选/确认流程作为操作教学说明，不伪造历史确认记录。MTX 演示与 scVI 选修不混入 H5 主线结论。

图解以实际图例、代码参数和导出表为准，原课件的部分注释仅作历史语境；资料馆保留原始字节，可下载核对。归一化目标本例为 5853，不是注释中举例的 10000。

## 目录与维护

| 位置 | 内容 |
|---|---|
| 两个 HTML 入口 | 地图交互与完整阅读/打印，共用同一内容 |
| content/*.md | 16 站可编辑正文 |
| content/stations.json | 站点、位置、自测、数据流 |
| content/figures.json、figure_types.json | 逐图详解及按类型说明 |
| content/glossary.json、术语覆盖.json | 术语源文与自动入口覆盖 |
| content/illustrations.json | 原理插画的完整文字解释 |
| assets/ | 本地样式、交互、地图、构建后的内容 JS 与 illustrations/*.svg |
| case/figures、tables、records | 精选原图、支撑表、历史摘要与运行记录 |
| case/historical | 当时的执行课件快照，用来核对历史，不直接续跑 |
| case/current | 当前模板、操作说明、选修与辅助源码的快照 |
| library/脚本与资料目录.html | 可阅读源码/课件和原文下载；下级目录对应 case 资料来源 |
| tools/build.py | 只读取本包重建页面，Python 需要 mistune |
| tools/draw_teaching.py | 重建 SVG 原理插画及其说明 |
| tools/glossary.py、*.html | 术语渲染与本地页面模板 |
| 素材来源.json / .tsv | 案例文件的复制来源、字节数与 SHA256 |
| REFERENCES.md | 方法和界面来源说明 |

维护时先修改 content 源文，再运行 `python -B tools/build.py`。修改插画时运行 `python -B tools/draw_teaching.py` 后重建。默认构建不读取原项目，不同步复制新结果；更新素材时应明确来源并更新清单。展示缓存、审核截图和维护者变更记录不在这个教程内。
