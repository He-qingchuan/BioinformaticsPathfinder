# 三个文件的详细解释
# 1. barcodes.tsv.gz - 细胞条形码文件
# 含义
# 包含每个细胞的唯一标识符（barcode）
# 每行代表一个细胞样本
# 总行数 = 细胞数量
# 2. features.tsv.gz - 基因特征文件
# 第一列（Gene ID）：
# Ensembl数据库中的唯一标识符
# 格式：ENSGXXXXXXXXXXXX
# 用于基因组浏览器、数据库查询
# 第二列（Gene Symbol）：
# 基因的常用名称/符号
# 更容易理解的名称（如TP53, ACTB）
# 第三列（Feature Type）：
# 特征类型标识：
# Gene Expression：标准mRNA表达
# 3. matrix.mtx.gz - 表达矩阵文件（核心数据）
# 三个数字（空格分隔）：
# 第1列：
# 行索引：基因的索引（从1开始）
# 第2列：
# 列索引：细胞的索引（从1开始）
# 第3列：
# 值：UMI计数（表达量）
