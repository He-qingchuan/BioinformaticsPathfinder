# web｜单细胞结果阅览

在课程根目录启动：

```bash
bash web/start.sh
# 若端口已占用，指定另一个空闲端口：
bash web/start.sh 8768
```

打开终端输出的 `http://127.0.0.1:8767`（或所选端口）。保留该终端，按 Ctrl+C 停止。脚本从自身位置寻找课程根目录，可以整体搬迁；不依赖本服务器路径。

服务器上的网页在服务器回环地址监听。自己的电脑需用编辑器“端口转发”，或运行 `ssh -L 8767:127.0.0.1:8767 用户名@服务器地址` 后在电脑浏览器打开同一地址。这里只提供本地阅读服务，没有公网账户与访问控制，不应直接改成公网监听。

## 怎么看

1. **当前项目**：选择自己的研究；`tutorial_example` 明确标为历史参考。不同项目的图表与报告分开。
2. **分析步骤**：阅读目的、方法、当前尝试、运行摘要、交互记录和有效解读。等待输入、等待确认、跳过、过期与失败分别显示。保存时状态与刷新后核验状态是不同概念。
3. **结果图册**：按章节、当前/历史尝试、候选路线、图形类型和文件类型筛选；每页 24 项。悬停或键盘聚焦看摘要，点击看原图和完整说明。可以适合窗口、原始尺寸查看及下载原件。
4. **数字表**：点击 CSV/TSV，预览数据并阅读逐列含义。保留重复列和双层表头；最多 80 行、512 列、1 MiB，完整表通过下载获取。原表空值不自动填 0。
5. **课件与说明**：读取当前项目 Notebook 的完整源码、注释及 Markdown 报告；Word 点击下载后打开。Notebook 输出图在图册查看。
6. **原理与读图**：页首进入同一端口下的固定海岛教程；它使用独立复制的骨髓材料，不随项目切换而变化。也可以直接打开 `tutorials/scrna_island/01_海岛探险教案.html` 离线学习。

本页只读已有产物，不调用 Notebook、模型或路线确认。完成分析、`review`、`redraw` 后点击“刷新项目与结果”。核验可能读取较大的检查点；期间显示“尚未核验”，不会用旧状态冒充完成。修改科学参数后继续按 99 指南重跑和更新报告。

## 图片说明与报告怎样更新

- 历史图片的详细说明绑定图片 SHA256；只有原图内容一致才使用该案例说明。重绘改变图片后，网页自动退回类型阅读提示，避免错误沿用旧数值。
- 新项目根据执行 Notebook 中明确的绘图调用提供阅读提示。未知图形明确待核对；不是自动生物学结论。AI 必须读原图、运行摘要、实际表格后撰写本章解读。
- 本章解读复用课程已有 `chapter_status` / `review_valid` 检查；过期正文不会作为“本章有效解读”显示。文档页和下载保留原文件供复查，不能把下载到旧文件理解为当前有效。
- 网页不重建 Word。用户改图后，AI 仍需 `redraw → 看图 → review/report`，随后刷新网页并下载更新后的 Word。
- `.viewer/thumbs/` 是每个项目内可删除、可重建的缩略图缓存，不是科学结果。原图时间/大小改变后更新；若不能写缓存则使用原图。需要完全不写缓存时：`SC_WEB_THUMBNAILS=0 bash web/start.sh`。

## 环境

通常先按根目录迁移说明运行 `bash setup.sh`。主环境已锁定 Tornado、Mistune、Pillow，无需 R/Shiny 或联网前端库。

只阅读既有结果时，可单独使用 Python 3.12 网页环境；这不代表科学分析环境已经验收：

```bash
conda create --prefix .envs/web python=3.12 pip
.envs/web/bin/python -m pip install -r web/requirements.txt
SC_WEB_PYTHON="$PWD/.envs/web/bin/python" bash web/start.sh
```

如果解释器/依赖缺失，启动脚本会明确停止。将已初始化的 `.envs/sc_rna` 直接搬家仍受 Conda 路径限制，按根目录迁移说明处理。静态海岛教程的已生成 HTML 不需要 Python 或 Conda。

## 文件导航（包括下级文件）

| 文件或目录 | 用途 |
|---|---|
| `start.sh`、`check_runtime.py`、`requirements.txt` | 相对路径启动、网页依赖检查、独立网页环境版本 |
| `app.py` | 本地 HTTP 服务；项目、状态、预览、下载和教程路由 |
| `viewer.py` | 扫描当前与历史尝试、受限文件路径、缩略图、Markdown/源码预览 |
| `check_status.py` | 只读子进程，调用原课程的状态和解读有效性判定 |
| `explanations.py` | 图形类型识别与表格字段解释；未知保持未知 |
| `descriptions/figures.json` | 各类图形的用途、坐标、编码、读法和边界 |
| `descriptions/case_catalog.json` | 历史案例逐图说明、生成代码与原图 SHA256 |
| `www/index.html`、`www/viewer.js` | 页面结构与交互；不进行分析 |
| `www/reference.css`、`www/viewer.css` | 参考项目海岛风格及本项目控件适配 |
| `tests/test_viewer.py` | 小型临时夹具的展示层测试，不在研究目录生成科学结果 |

维护时在临时课程副本修改并审核，新增图形需要实际看图、对照源代码及表格后补充说明。不要把浏览器测试截图、维护记录或临时项目放进学生包。
