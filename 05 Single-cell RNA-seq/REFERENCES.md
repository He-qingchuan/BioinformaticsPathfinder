# 来源与核对

案例复制来源为同课程 projects/tutorial_example，来源与 SHA256 见素材来源清单。界面样式、地图建筑、课程/术语/图解交互基于用户提供的 rnaseq_analysis/tutorials/rnaseq_island，在复制件中适配单细胞内容；未改变参考项目。没有引入远程字体、在线脚本或 CDN。

方法以包内生成代码、实际表格与图例为依据。下列官方资料用于概念与参数核对；查询日期 2026-09-17，当前网站版本可能高于案例所用 Scanpy 1.11.5 / AnnData 0.12.19。

- [AnnData 对象结构](https://anndata.readthedocs.io/en/stable/generated/anndata.AnnData.html)：X、注释、层与低维表示。
- [Scanpy dotplot](https://scanpy.readthedocs.io/en/stable/generated/scanpy.pl.dotplot.html)：点大小、均值与显示缩放。
- [Scanpy 官方文档](https://scanpy.readthedocs.io/)：其他方法以本地安装版本的函数说明及历史执行参数核对。
- [CellTypist 模型目录](https://www.celltypist.org/models)：仅作为今后资源检查入口；模型选择应实时核对物种与组织，教程不声称该目录永不变化。

图解没有用外部教材长段落替代案例说明。教学 SVG 为本次原理示意，非真实测量；原始统计图保持原字节。
